    What the words mean
    LaunchpadA site that lets anyone create a token in a few clicks, like pump.fun on Solana or clanker on Base.
    Launch score0 to 100. Higher means more trading going on and fewer other tokens competing for buyers.
    Took offA new token that reached $100K in total value within its first day.
    GraduatedOn bonding-curve launchpads (like pump.fun), the token sold enough to move to a real trading pool.
    Best dayThe weekday when that chain's launchpads usually trade the most (typical of the last 6 weeks).
    Best timeThe 3 hours with the most memecoin trading for each new token launched, so buyers aren't spread thin.
    vs last weekThe last 3 days compared with the same 3 days a week before, so weekends compare with weekends.
